# Player Partner

一个给 Minecraft **1.21.1 / NeoForge** 准备的小模组：添加一个只有玩家一半体型的小伙伴，它会使用真实 Minecraft 玩家的皮肤，还能像玩家一样穿装备、带背包、会饿也会自己吃东西。

## 功能

- **玩家伙伴（Player Partner）**：身高、碰撞箱都是普通玩家的一半（0.3 x 0.9 格），会四处走动、看着附近的玩家。
- **对玩家友好**：伙伴永远不会攻击玩家或任何其它生物，也不会因为离得太远而消失，可以放心带着到处跑。
- **用命名牌换皮肤**：拿着写有正版玩家 ID 的命名牌右击它，伙伴就会自动加载并显示那个玩家的皮肤（宽臂 / 细臂自动匹配）。
- **默认皮肤**：没有命名时，默认显示作者 **ChinaEX123_BILI** 的皮肤（皮肤图片已打包在模组里，断网时也能正常显示）。
- **错误提示**：如果输入的 ID 不存在，聊天栏会提示“找不到名为 xxx 的正版账号”；如果是网络问题，则会给出单独的联网错误提示，方便区分是输错了还是没网。
- **背包与装备**：潜行 + 右击伙伴可以打开它的背包界面，界面上方是 6 个装备槽（主手、副手、头盔、胸甲、护腿、靴子），下方是它自己的 27 格储物栏。放进去的武器、盔甲会直接显示在身上。
- **饥饿与进食**：伙伴拥有和玩家一样的饥饿值（界面上有饥饿条），会消耗饥饿度；饿了会自己找食物放到副手吃掉。它会优先吃没有负面效果的食物，只有实在没有别的东西吃的时候，才会去吃腐肉这类带负面效果的食物。
- **不捡东西**：伙伴不会主动拾取地上的掉落物，掉在脚边的东西不会被它捡走。

## 使用方法

1. 在创造模式物品栏（刷怪蛋分类）里找到 **玩家伙伴刷怪蛋**，或者用命令生成：
   ```
   /summon player_partner:player_partner ~ ~ ~
   ```
2. 用铁砧把命名牌改成正版玩家的游戏 ID（例如 `Notch`），右击伙伴即可换皮肤。
3. 想恢复默认皮肤，把命名牌改回 `ChinaEX123_BILI` 再右击即可。
4. **潜行（Shift）+ 右击**伙伴打开它的背包：给它的主手、副手放武器，给盔甲槽放盔甲，它就会穿戴上。
5. 给它的储物栏里放些食物，等它饿了会自动拿出来吃。

## 关于“被游戏视为玩家”

原版里真正的“玩家”只有 `ServerPlayer` / `RemotePlayer` 两种实现，由玩家列表（`PlayerList`）管理，还要处理登录、联机同步、计分板、聊天等一整套逻辑。让一个生物直接继承 `Player` 会同时破坏生物 AI 和单人/联机两端的生命周期，所以本模组没有这么做。

伙伴走的是“**玩家式能力**”方案：和玩家一样使用 6 个装备槽（含主手 / 副手）与玩家模型渲染（因此能显示皮肤、穿盔甲、手持物品）、有自己的物品栏和饥饿值、能像玩家一样“使用物品”吃食物。它**不会**被计分板、队伍、玩家列表、聊天当作玩家，也不会被 `/tp @p` 之类的玩家选择器选中——如果你需要这些行为，后面可以针对具体功能单独补。

## 说明

- 皮肤是通过 Mojang 官方接口按 ID 查询的，因此**需要联网**；查询只在客户端进行。
- 服务器上使用时，服务端和客户端都需要安装本模组。
- 模组只根据玩家 ID 查询皮肤，不需要登录，也不会接触任何账号信息。

## 构建

需要 JDK 21：

```
gradlew.bat build
```

产物在 `build/libs/player_partner-1.0.0-mc1.21.1-neoforge.jar`。
